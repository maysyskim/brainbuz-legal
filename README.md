# BrainBuz 서비스 문서

GitHub Pages 게시용 정적 문서입니다. 외부 라이브러리·분석 도구·로그인·폼을 사용하지 않습니다. 현재 내용은 검토용 초안이며 실제 가입 동의에 사용하지 않습니다.

## GitHub Pages 게시

1. GitHub에 약관 전용 공개 저장소 `brainbuz-legal`을 만듭니다.
2. **이 폴더 안의 파일만** 저장소 `main` 브랜치의 최상위에 업로드합니다.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. GitHub가 표시하는 실제 배포 URL에서 문서 목록과 두 문서를 확인합니다.

주소 형식(실제 배포 주소 아님): `https://계정명.github.io/brainbuz-legal/`.

현재 문서 경로: `draft-2026-09-18-terms.html`, `draft-2026-09-18-privacy-consent.html`.
운영자명·문의처·보관 기준 등을 확정한 뒤 별도 정식 버전 경로로 게시하고 Supabase 약관 설정에 등록하세요.
앱 소스, APK, 서명 키, 서버 설정은 이 저장소에 업로드하지 않습니다.
