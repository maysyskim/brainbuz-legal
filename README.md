# BrainBuz 서비스 문서

GitHub Pages 게시용 정적 문서입니다. 외부 라이브러리·분석 도구·로그인·폼을 사용하지 않습니다.

## GitHub Pages 게시

1. GitHub에 약관 전용 공개 저장소 `brainbuz-legal`을 만듭니다.
2. **이 폴더 안의 파일만** 저장소 `main` 브랜치의 최상위에 업로드합니다.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. GitHub가 표시하는 실제 배포 URL에서 문서 목록과 두 문서를 확인합니다.

공개 주소: https://maysyskim.github.io/brainbuz-legal/

고정 경로: `terms.html`, `privacy-consent.html`.
버전 경로: `2026-09-18-terms.html`, `2026-09-18-privacy-consent.html`.
과거 draft 경로는 이전 검토본으로 보존합니다. 앱 연결 및 운영 기능 배포는 문서 게시와 별도로 관리합니다.
앱 소스, APK, 서명 키, 서버 설정은 이 저장소에 업로드하지 않습니다.
