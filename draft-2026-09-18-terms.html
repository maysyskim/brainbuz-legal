2. 계정과 가입

이용자는 지원되는 외부 계정으로 인증한 뒤 필수 이용약관·개인정보 수집·이용 동의와 닉네임 등록을 마쳐 회원가입을 완료합니다. 외부 계정 인증 과정에서 인증 서비스에 사용자 식별 정보가 먼저 생성될 수 있습니다. 다른 사람의 계정을 무단으로 사용하거나 타인을 사칭해서는 안 됩니다. 외부 서비스의 로그인·메시지 권한은 해당 서비스의 정책과 동의 범위를 따릅니다.

3. 기능 사용

AI가 생성한 답변은 오류나 부정확한 내용을 포함할 수 있습니다. 이용자는 실제 행동이나 전송 전에 내용을 확인해야 합니다. 메시지 전송은 수신자와 내용을 확인한 뒤 실행합니다. 목소리 확인 기능은 편의 기능으로, 고위험 거래나 신원 확인을 위한 보안 수단으로 제공되지 않습니다. 집중·휴식 기능은 질환의 진단이나 치료를 목적으로 제공되지 않습니다.

온라인 AI·실시간 음성·외부 메시지 등 일부 기능에는 인터넷과 외부 서비스 연결이 필요합니다. 이용자가 설정한 외부 API 이용료와 통신 요금은 해당 제공자의 계약에 따릅니다. 별도의 유료 서비스 도입 시 가격과 결제 조건을 사전에 표시합니다.

4. 이용자의 의무와 콘텐츠

타인의 개인정보·음성·저작물을 권한 없이 수집하거나 전송하지 않아야 합니다. 불법적인 사칭, 스팸 전송, 서비스 방해와 접근 제한 우회는 허용되지 않습니다. 이용자가 입력한 콘텐츠의 권리는 원래 권리자에게 남으며, 서비스 제공에 필요한 처리 범위는 개인정보 문서와 기능별 안내를 따릅니다.

5. 변경·중단과 이용 제한

운영자는 유지보수·장애·외부 서비스 변경 등으로 기능을 변경하거나 일시 중단할 수 있습니다. 이용에 중요한 변경은 가능한 범위에서 사전에 알리고, 긴급 장애 등 사전 안내가 어려운 경우 사후 안내합니다. 위반 행위에 대한 이용 제한은 사유와 범위를 설명하고 문의·이의제기 경로를 제공합니다.

6. 탈퇴와 데이터

이용자는 앱의 내 계정에서 회원 탈퇴를 요청할 수 있습니다. 서버의 회원 프로필·가입 동의 기록과 인증 계정은 삭제 처리합니다. 카카오의 서비스 연결 해제와 기기에 남은 대화·음성 설정 삭제는 별도 안내에 따릅니다. 백업·접속 로그·중도 이탈 계정의 구체적인 보관 기준은 운영 정책 확정 후 개인정보 문서에 기재합니다.

운영자와 이용자의 책임은 관련 법령에 따릅니다. 이 약관은 운영자의 고의·중과실 책임이나 이용자에게 법령상 보장된 권리를 배제하지 않습니다. 서비스 관련 문의와 분쟁은 게시된 문의처를 통해 접수할 수 있으며 해결되지 않은 분쟁은 관련 법령의 절차를 따릅니다.

약관 변경 시 변경 내용과 시행일을 안내합니다. 새 필수 약관에 대한 동의가 필요한 경우 앱에서 다시 확인합니다. 이전 버전은 버전별 주소로 보존합니다.
